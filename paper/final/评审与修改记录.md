# 评审与修改记录

按任务要求模拟 5 位评审，各自从一个角度通读排版后的全文（`竞赛论文.docx` 的 PDF 预览与填充数字后的 Markdown），共两轮。第一轮提出的问题逐条修改；第二轮复查修改结果，剩余问题写入论文“模型的局限”或下面的“未改动项”。评审角色：

| 编号 | 角色 | 关注点 |
|:--|:--|:--|
| R1 | 建模方法评审 | 记号、定义、定理与证明是否严谨，模型与评估器是否一致 |
| R2 | 领域评审（编译调度 / NPU 体系结构） | 机制解释是否站得住，算法描述是否与代码一致 |
| R3 | 实验与统计评审 | 数字口径、对照公平性、显著性检验、子集实验的说明 |
| R4 | 写作评审 | 可读性、用词、前后一致、中文排版 |
| R5 | 竞赛规范评审 | 赛题要求的输出是否齐全，《格式规范》逐项 |
