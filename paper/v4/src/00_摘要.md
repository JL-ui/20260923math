%% TITLE: 基于跨核同步层次分层的通用 NPU 多核切图与调度
%% KEYWORDS: 多核 NPU；计算图切分；跨核同步层次；容量感知表调度；模拟退火

::: abstract
多核 NPU 运行一张计算图时，需要联合确定切图、分核与同核子图的执行顺序。本文把计算图中除 COPY_IN、COPY_OUT 以外的操作节点称为算子，以算子到子图、子图到核心的映射和各核心的子图顺序为决策变量，以 Makespan 为主目标、总额外数据搬运量为次目标，建立三个问题共用的优化模型，全部结果以评估程序在固定配置下的输出为准。分析评估程序后发现，核内调度对申请片上张量的算子施加全局申请序，排在核内序列前部而数据尚未到达的跨核 COPY_IN 会使整个核心的四条流水线同时等待。据此定义跨核同步层次，以“核心—层次”等价类构造子图，使子图依赖无环、同核顺序合法等结构约束由构造满足；这一构造与通信感知的无环分块、块级局部搜索和评估程序择优组合成 CAP-LS 算法，是本文的主要创新。消融实验表明，在单一候选配置下去掉同步层次分层，三个问题 $N=2\sim5$ 的平均加速比分别下降 @@ABL_P1_NO_LEVEL_ABS@@、@@ABL_P2_NO_LEVEL_ABS@@ 和 @@ABL_P3_NO_LEVEL_ABS@@。

针对问题一（无核间同步，子图即 Task），建立描述边界搬运、同核切换与跨核等待的 Task 级时序模型，分析子图粒度在边界搬运与换入换出之间的折中，并以该模型为适应度，用模拟退火调整 Task 的粗细与核心分配。在 100 个用例上，$N=2\sim5$ 的平均加速比为 @@P1_MEAN_LIST@@，$N=4$ 时比四类基线中表现较好的通信聚类方法高 @@VSB4_P1_REL_ABS@@；单个（用例，核数）配置的求解时间中位数为 @@P1_RT_MED@@ s。

针对问题二（有核间同步，核心即 Task），同核子图边界不再产生搬运，切图主要决定核内执行顺序。推导各核搬入、搬出字节的解析式，说明跨核搬运可写成以张量字节为权的 $(\lambda-1)$ 超图割；另增加单算子子图与容量感知表调度候选，在控制片上驻留的同时让 Cube 与 Vector 计算交替进行，使 $N=4$ 时所选方案的换入换出总量减少 @@SPILL_DROP@@。$N=2\sim5$ 的平均加速比为 @@P2_MEAN_LIST@@，$N=4$ 时比通信聚类方法高 @@VSB4_P2_REL_ABS@@。

针对问题三（共享只读 L2 Cache），由 FIFO 命中规则推出命中只来自多核复读与同核重复读入，给出命中字节上界与“复用距离不超过容量、后续读取晚于首次读入完成”的时序条件，并把预测命中折算进分配代价。只读 Cache 配置 $N=2\sim5$ 的平均加速比为 @@P3_MEAN_LIST@@，$N=4$ 时比通信聚类方法高 @@VSB4_P3_REL_ABS@@；同一方案在无 L2 与只读 Cache 下的 Makespan 之比在 $N=1\sim5$ 时平均为 @@L2SAME_LIST@@，按字节命中率在 @@HIT_RANGE@@ 之间；$N\ge2$ 时核数越多，L2 的收益越明显。
