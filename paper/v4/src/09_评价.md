# 模型评价与推广 {#sec:ch9}

## 模型的优点

（1）**模型结构与评价口径一致。** 边界搬运模型逐条对应评估程序的 COPY 插入规则，与评估程序输出逐项吻合（[@sec:p1model]）；同步层次分层的依据是从核内调度中读出的全局申请序，并在执行轨迹上得到印证（[@fig:trace]）。近似只出现在搜索代理中，上报结果全部来自评估程序。

（2）**结构约束由构造满足。** 由性质 1、2，按单调层指派形成的方案自动满足（C1）～（C5），候选生成过程不需要反复判环，单个候选的构造时间很短（[@sec:p1eff]）。

（3）**三个问题共用一套流程。** 三个问题的差别集中在同步权重、候选集合与 L2 折算三处，问题二、三新增的表调度与 Cache 感知代价都嵌在同一流程中。消融显示同步层次分层与通信感知分块在三个问题上都起作用（[@tbl:ablation]），标准求解流程在三个问题上都高于最强基线（[@tbl:baselines]）。

（4）**结果稳定，可以复现。** 流程含整图单核与更少核数补空核两类兜底候选，1200 个配置的加速比都不低于 1 且随核数单调不降，受影响的 @@MONO_FIX_N@@ 个配置已逐个复核（[@sec:stdsrc]）。随机过程固定种子，评估结果按方案哈希缓存，重复运行得到相同结果；加速比超过核数、L2 收益随核数增大、问题三个别配置慢于问题二等现象，分别可由[@eq:su]、[@eq:dt]与[@eq:cond]、规则（5）解释。

## 模型的缺点 {#sec:weak}

（1）**大图的求解时间。** 问题一中评估最慢的 4 个用例采用代理筛选，候选之间凭代理选择；问题一有 @@P1_RT_OVER_CASES@@ 个用例的部分配置超过 10 分钟，耗时主要在评估程序上。单次评估达到数分钟以上时，候选网格与退火都要按时间预算裁剪，结果会向单一候选的水平退化（[@sec:proxy]）。

（2）**择优只比较 Makespan。** [@eq:obj]是字典序目标，而择优时只比较 Makespan，Makespan 相同时取先评估的候选。在 @@LEX_TIE_TOT@@ 个配置中，有 @@LEX_TIE_N@@ 个存在 Makespan 相同但额外搬运量更小的候选。

（3）**代理精度与 Cache 感知调度。** 问题二、三的解析代理在用例内的排序一致性为中等，需要依赖评估程序择优。问题三的代价不模拟 FIFO 淘汰与发射时刻的命中判定，这两类情形对应的未命中字节占比较高（[@sec:p3result]）；读取同一张量的各核在时间上过于集中或过于分散时，[@eq:mte2]的预测会明显偏高，问题三在部分配置上慢于问题二。

（4）**结构性难例与子集实验。** 对 case_016 这类长同步链结构，子图级切分的空间有限，方法既不改动核内调度，也不做算子内部的切分。粒度与硬件灵敏度实验只在子集上进行，L2 容量与带宽的结论不能推广到复用较多的用例。

## 模型的改进与推广 {#sec:extend}

（1）**跨场景候选复用与字典序择优。** 在问题三中把问题二的方案也作为候选，可以减少问题三慢于问题二的情形；在 Makespan 相同的候选中取额外搬运量最小者，可使择优规则与[@eq:obj]完全一致。

（2）**Cache 感知的核内顺序。** 由[@eq:cond]，读取同一共享张量的各核在时间上既不宜过于集中，也不宜相隔过远。把复用距离加入表调度的评分[@eq:score]，可能减少并发首读与 FIFO 淘汰两类未命中，需要实验验证。

（3）**更快的评估。** 若能实现与评估程序结果一致的快速评估，大图的代理筛选可以取消，求解时间也更容易控制在 10 分钟以内。

（4）**更一般的场景。** 同步层次分层依赖的是“跨核依赖的实际代价明显高于名义延迟”这一性质，对具有类似性质的多核、多芯粒调度问题[[gemini,stream]]可能同样适用。对规模更大的图，可以把 S1 换成成熟的超图或有向无环划分器[[mtkahypar,herrmann]]。算子内部切分需要改写计算图，超出本文所定义的方案形式。

## 总结 {#sec:summary}

本文研究多核 NPU 上切图、分核与同核子图排序的联合优化，以评估程序给出的 Makespan 为主目标。模型以算子到子图、子图到核心的映射与各核子图顺序为决策变量，把硬约束写成（C1）～（C9）。根据核内调度的全局申请序，定义跨核同步层次 $r(v)$，以（核心，层次）等价类形成子图，使（C1）～（C5）由构造满足。求解采用 CAP-LS：通信感知的无环分块、块级核心分配的局部搜索、按同步层次形成子图，再由评估程序在预定义候选中择优。问题一在此基础上建立 Task 级时序模型，用模拟退火调整 Task 粒度；问题二利用同核边界零搬运的性质，增加单算子子图与容量感知表调度候选；问题三由 FIFO 命中规则得到命中来源与时序条件，把预测命中折算进分配代价。$N=2\sim5$ 时，三个问题的平均加速比分别为 @@P1_MEAN_LIST@@、@@P2_MEAN_LIST@@ 与 @@P3_MEAN_LIST@@。
