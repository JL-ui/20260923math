# 模型假设 {#sec:ch2}

（1）**评价以评估程序为准。** Makespan、总额外搬运量与 Cache 命中率一律取评估程序在固定配置下的输出；模型推断与评估程序行为不一致时，以评估程序为准。模型中的解析式只用于搜索内部的候选排序，不作为上报结果。

（2）**核内调度视为确定映射。** 核内 Step1～Step3 是给定的确定性过程，方案只能通过子图划分与子图顺序间接影响核内算子次序与换入换出。模型把它视为“子图序列 → 核内算子次序与换入换出”的确定映射，不对其改写。

（3）**核心同构，流水线独占。** $N$ 个核心的计算单元、流水线结构与私有缓存容量相同；每核每条流水线同一时刻只有一条在飞指令，四条流水线之间可以并行，Cube 与 Vector 计算可以相互重叠。因此分核只需考虑负载与通信，不必区分核心。

（4）**DDR 公平共享。** $n$ 个在途 DDR 搬运各得 $1/n$ 的总带宽，搬运加入或完成时重新分配；一次搬运的时长由字节数与实际分得的带宽决定。问题三中 L2 命中的读取以 250 B/cycle 进行，不占用 DDR 带宽池。

（5）**方案形式固定。** 方案只能给出算子到子图的映射与各核的子图顺序，不能改写计算图，也不能把单个算子再切分。

（6）**Task 时长近似。** 在场景解析模型与搜索代理中，一个 Task 或一个核心的时长用四条流水线中最忙者的占用近似，忽略 Task 内部的换入换出与 DDR 争用。这一近似只用于候选之间的相对比较，其排序能力在[@sec:proxy]中检验。

（7）**命中预测近似（仅问题三）。** 在分配代价中，一个要从 DDR 读入多个核心的张量，按“第一个读入核未命中、其余读入核命中”估计命中字节，不模拟 FIFO 淘汰与发射时刻的先后。该估计对命中偏乐观，候选之间的取舍由评估程序纠正。

（8）**求解预算。** 单个候选的构造与局部搜索时间应远小于一次评估；算法不对“切图 × 分核 × 排序”做枚举，评估很慢的大图允许先用代理在候选之间预筛。

| $G=(V,E)$，$V=T\cup O$ | 原始计算图；张量节点集与操作节点集 |
