# 基本规则、模型假设与符号 {#sec:ch2}

## 评估规则与硬件规则 {#sec:rules}

以下内容由题目或评估器实现直接给定，模型把它们作为事实使用，而不是作为简化假设。

（1）**评价口径。** Makespan、总额外搬运量与 Cache 命中率一律以评估器在固定配置 `data/config.txt` 下的输出为准；模型推断与评估器行为不一致时，以评估器为准。

（2）**核内调度固定。** 核内 Step1～Step3 是给定的确定性过程，方案只能通过子图划分与子图顺序间接影响核内算子顺序和换入换出。

（3）**核心同构。** $N$ 个核心的计算单元、流水线结构与私有缓存容量相同。

（4）**流水线独占。** 每核每条流水线同一时刻只有一条在飞指令，四条流水线之间可以并行，Cube 与 Vector 计算可以重叠。

（5）**DDR 公平共享。** $n$ 个在途 DDR 搬运各得 $1/n$ 的总带宽，搬运加入或完成时重新分配；一次搬运的时长由字节数与实际分得的带宽决定。

（6）**只读 L2 语义（仅问题三）。** 仅 COPY_IN 查询 Cache，命中键为写入片上的逻辑张量编号；是否命中在发射时判定，命中时以 250 B/cycle 读取且不占用 DDR 带宽池；未命中的读取走 DDR，完成时写入 Cache；按 FIFO 淘汰，命中不改变条目顺序，大于容量的张量不写入。

（7）**方案形式。** 方案只能给出算子到子图的映射与各核子图顺序，不能改写计算图，也不能把单个算子再切分。

## 模型假设 {#sec:assume}

以下是为建模与求解所作的简化，它们只影响搜索内部的候选排序，不影响上报结果的口径。

（1）**Task 时长近似。** 在场景解析模型与搜索代理中，一个 Task 的时长用四条流水线中最忙者的占用近似，忽略 Task 内部的换入换出与 DDR 争用；这一近似只用于候选之间的相对比较。

（2）**命中预测近似（仅问题三）。** 在分配代价中，一个要从 DDR 读入多个核心的张量，按“第一个读入核未命中、其余读入核命中”估计命中字节，不模拟 FIFO 淘汰与发射时刻的先后。该估计对命中偏乐观，由评估器择优来纠正。

（3）**求解预算。** 单个候选的构造与局部搜索时间应远小于一次评估，算法不对“切图 × 分核 × 排序”做枚举；评估很慢的大图允许先用代理在候选之间预筛。

## 符号说明 {#sec:symbols}

: 符号说明 {#tbl:symbols widths=2.4,6.2}
| 符号 | 说明 |
|:---:|:---|
| $G=(V,E)$，$V=T\cup O$ | 原始计算图，张量节点集与操作节点集 |
| $V_{op}$，$E_{op}$ | 可切分算子集（非 COPY 操作）与收缩 COPY 后的算子级依赖边集 |
| $s_t$ | 张量 $t$ 的字节数 |
| $c_v$，$p_v$ | 算子 $v$ 的周期数与所在流水线 |
| $P_t$，$C_t$ | 张量 $t$ 的生产者集合与消费者集合 |
| $N$ | 核心数 |
| $x_v$，$y_s$，$\pi_k$ | 决策：算子 $v$ 的子图、子图 $s$ 的核心、核 $k$ 上的子图顺序 |
| $c(v)=y_{x_v}$ | 算子 $v$ 所在的核心 |
| $r(v)$，$l(v)$ | 跨核同步层次（最早合法层）与一般的单调层指派 |
| $\sigma$ | 算子级 DAG 的一个线性扩展（拓扑序） |
| $\theta$，$\beta$ | 张量扇出阈值；粒度参数（单块计算量上限 $\beta W/N$） |
| $C_{L1}$，$C_{UB}$，$C_{L2}$ | L1、UB、L2 的容量 |
| $bw$，$bw_{L2}$ | DDR 总带宽 60 B/cycle，L2 带宽 250 B/cycle |
| $W_{same}$，$W_{cross}$ | 场景 A 同核切换等待 100 cycle，跨核等待 1000 cycle |
| $\delta$ | 场景 B 跨核同步延迟 500 cycle |
| $L_k^{M}$，$L_k^{V}$ | 核 $k$ 上 Cube、Vector 计算的总周期 |
| $B_k^{in}$，$B_k^{out}$，$B_{DDR}$ | 核 $k$ 的搬入、搬出字节数，方案的 DDR 搬运总字节 |
| $F$ | 搜索代理函数（仅用于候选排序与局部搜索） |
| $\mathrm{MK}_N$，$\mathrm{SU}_N$ | $N$ 核 Makespan；加速比 $\mathrm{MK}_1/\mathrm{MK}_N$ |
| $\mathrm{LB}_N$ | $N$ 核 Makespan 的理论下界 |
