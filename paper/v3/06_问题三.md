# 问题三模型的建立与求解 {#sec:ch6}

## 问题特点

问题三在场景 B 上加入所有核心共享的只读 L2 Cache（1 MB，250 B/cycle，带宽独立于 DDR），要求分析其容量与带宽对切图与调度的影响。只读 Cache 只服务 COPY_IN，不改变跨核依赖的结构，改变的是重复读取的代价：在问题二中，把一个被多核读取的张量分别读到多个核心全部是额外搬运；有了 L2，第二次起的读取可能以约四倍的速度完成，且不占用 DDR 带宽。命中又取决于 FIFO 淘汰和发射时刻，与切图、调度相关。问题三的求解按“命中机制—Cache 感知代价—求解—实验”展开（[@fig:flow3]）。

![问题三求解流程图](figures/v3/fig_flow_p3.png){#fig:flow3 width=11.6}

## 只读 L2 的命中机制 {#sec:l2model}

由规则（6）与机制 5，一个张量能命中的前提是它此前已被某个 COPY_IN 从 DDR 读入并写入 Cache。满足这一前提的读取只有两类：同一张量被多个核心各自读入（图输入张量、跨核中间张量），第一次未命中并写入 Cache，之后的读取可能命中；同一核心对同一逻辑张量的再次读入（释放后重读，或换出后换入）。定义张量 $t$ 的复用度与 Cache 价值为

$$
\mathrm{reuse}(t)=\bigl\lvert\{\text{对 }t\text{ 的 COPY\_IN}\}\bigr\rvert,\qquad \mathrm{value}(t)=s_t\,\bigl(\mathrm{reuse}(t)-1\bigr)\,\mathbb{1}[s_t\le C_{\mathrm{L2}}]
$$ {#eq:reuse}

$\sum_t\mathrm{value}(t)$ 是命中字节的上界。一次命中节省的搬运时间为 $s_t(1/bw-1/bw_{\mathrm{L2}})$，于是

$$
\Delta T_{\mathrm{L2}}\ \le\ \sum_t\mathrm{value}(t)\Bigl(\frac{1}{bw}-\frac{1}{bw_{\mathrm{L2}}}\Bigr)=@@L2_DT_COEF@@\sum_t\mathrm{value}(t)
$$ {#eq:dt}

命中的读取不进入 DDR 带宽池，相当于把 DDR 争用减少了同样的字节数，在带宽受限的用例上还有额外收益。

上界能否达到取决于时序。记张量 $t$ 写入 Cache 之后、最后一次读 $t$ 之前写入 Cache 的字节数为复用距离 $D_t$。在 FIFO 且命中不刷新的规则下，$t$ 的后续读取全部命中的条件是

$$
D_t+s_t\le C_{\mathrm{L2}}\quad\text{且}\quad \text{后续读取的发射时刻晚于首次读入的完成时刻}
$$ {#eq:cond}

两个条件方向相反：读 $t$ 的各个核心相隔太远，$D_t$ 变大，$t$ 在被复用前已被淘汰；相隔太近，后续读取在首次读入完成前就已发射，同样不命中。L2 与切图、调度的关联就在这里。

## Cache 感知的分配代价 {#sec:l2cost}

问题三把预测命中折算进 S2 的代理 $F$：核心 $k$ 的 `PIPE_MTE2` 占用由 $B_k^{\mathrm{in}}/bw$ 改为

$$
\frac{B_k^{\mathrm{in}}-H_k}{bw}+\frac{H_k}{bw_{\mathrm{L2}}}
$$ {#eq:mte2}

全局 DDR 项由 $B_{\mathrm{DDR}}/bw$ 改为 $(B_{\mathrm{DDR}}-\sum_k H_k)/bw$。$H_k$ 为核心 $k$ 的预测命中字节，按模型假设（2）计算：对每个要从 DDR 读入多个核心的张量，第一个读入核按未命中计，其余读入核按命中计，大于 $C_{\mathrm{L2}}$ 的张量不计。这一改动使重复读取的代价下降，分核可以更多地考虑负载均衡与并行。[@eq:mte2]不模拟 FIFO 淘汰与[@eq:cond]的时序条件，对命中是乐观估计，候选之间的取舍仍由问题三评估器决定。除代价中的 L2 折算外，问题三的候选网格、表调度与采样都与问题二相同。

## L2 容量与带宽的影响 {#sec:l2sens}

**模型推断。** 由[@eq:dt]，L2 带宽决定单次命中的收益系数 $1/bw-1/bw_{\mathrm{L2}}$。$bw_{\mathrm{L2}}\to\infty$ 时系数趋于 $1/bw$，题设的 250 B/cycle 已达到这一上限的 @@L2_COEF_250@@，降到 125 B/cycle 时为 @@L2_COEF_125@@；降到与 DDR 相同的 60 B/cycle 时单次命中不再更快，只剩不占 DDR 带宽池的收益。容量通过[@eq:cond]的第一个条件起作用：它决定一个被多核复读的张量能否在全部读者读完之前留在 Cache 中。容量越小，要求各读者在时间上越集中；容量足够大时，命中只受第二个条件与 $\mathrm{value}(t)$ 的限制。

**子集实验。** [@tbl:l2sens]在 @@SENS_CASES@@ 个用例、$N=4$ 上把 L2 容量在 64 KB～16 MB、带宽在 60～1000 B/cycle 之间变动，在修改后的参数下重新求解并评估。该实验改动了硬件参数，只作研究用途，其评估缓存与正式结果物理隔离。表中数值为题设参数下的 Makespan 与变动后 Makespan 之比的几何平均，大于 1 表示变快。

### 无 L2 与只读 Cache 的对比

评测要求给出 1～5 核下无 L2 与只读 Cache 两种配置的对比，以及相同核数下只读 Cache 相对无 L2 的加速比 $\mathrm{MK}_{\text{无 L2}}/\mathrm{MK}_{\text{只读}}$。这一比值有两种口径，含义不同，[@tbl:l2cmp]分别列出。

（1）**配置最优性能比较。** 无 L2 配置取问题二的标准流程方案，只读 Cache 配置取问题三的标准流程方案，两者各自在本配置下择优。它回答“在各自配置下求解，最终性能差多少”，同时包含 L2 硬件的作用和两次求解所选方案不同带来的差异。

### 命中与未命中的来源

对问题三方案重跑评估器，读取 Cache 事件流并按张量分类（[@fig:l2src]），逐项求和与评估器输出的命中、未命中字节一致。该拆分是在离线候选扩展后的方案（[@sec:offline]）上完成的，标准流程方案尚未重做这一统计，下列比例只作量级参考。$N=4$ 时，@@HIT_INPUT_N4@@ 的命中字节来自图输入张量的重复读入，跨核中间张量占 @@HIT_CROSS_N4@@。未命中字节中，@@MISS_FIRST_N4@@ 是每个张量的首次读入，@@MISS_CONC_N4@@ 是多个核心在首次读入完成前并发读取同一张量，@@MISS_FIFO_N4@@ 是写入后被 FIFO 淘汰、之后再读。后两类对应[@eq:cond]的两个条件，在 $N=4$ 的统计中合计约占未命中字节的 @@MISS_AVOID_N4@@；[@eq:mte2]没有对它们建模，这部分是 Cache 感知调度的进一步优化空间（[@sec:weak]）。

### 问题三与问题二的比较

任何问题二的方案都是问题三的可行方案，但问题三的结果不保证不慢于问题二，原因有两层。第一层是 FIFO Cache 的时序效应（机制 5）：命中让部分 COPY_IN 提前完成，改变了后续搬运的完成顺序与 DDR 带宽的分配时序，关键路径上的个别操作可能因此略晚完成。把同一方案分别交给两个评估器，400 个配置中有 @@SAME_SLOW_N@@ 个在只读 Cache 下更慢，最大相对差 @@SAME_SLOW_MAX@@。这与列表调度中资源增加反而变慢的时序异常同类[[graham]]。第二层是两次求解所选方案不同：标准流程下，问题三在 @@P3SLOW_ALL_N@@/400 个配置上慢于问题二，相对差的中位数为 @@P3SLOW_ALL_MED@@，最大为 @@P3SLOW_ALL_MAX@@（@@P3SLOW_ALL_MAXC@@）。$N=4$ 时，问题三在 @@P3VSP2_FASTER@@ 个用例上快于问题二，@@P3VSP2_EQUAL@@ 个相等，@@P3VSP2_SLOWER@@ 个更慢（[@fig:p2p3]）。

离线候选扩展后，问题二的方案也放进问题三的候选中比较，第二层差异随之消失，只剩第一层：400 个配置中仍有 @@P3EXC_N@@ 个例外，即 @@P3EXC_1@@ 与 @@P3EXC_2@@（括号内为问题三与问题二的 Makespan，单位 cycle），最大相对差 @@P3EXC_MAXREL@@。
