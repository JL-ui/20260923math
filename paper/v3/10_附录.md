##* 附录C 核心程序（节选）

**（1）跨核同步层次与子图成形**（`solution/npu/stratify.py`，对应定义 3-1 与引理 3-1）

```python
def cross_core_levels(g, core_of_op):
    """r(v)：沿依赖路径累计的换核次数（拓扑序一次扫描）。"""
    level = {}
    for v in g.topo:
        cv = core_of_op[v]
        best = 0
        for p in g.preds[v]:
            cand = level[p] + (1 if core_of_op[p] != cv else 0)
            best = max(best, cand)
        level[v] = best
    return level


def build_subgraphs(g, core_of_op, num_cores, rank, max_ops=None, levels=None):
    """子图 = (核心, 层次) 等价类，按 (层次, 核心, 切片序) 递增编号。"""
    levels = levels if levels is not None else cross_core_levels(g, core_of_op)
    check_monotone(g, core_of_op, levels)          # 显式层指派须满足推论 3-3 的单调性
    buckets = defaultdict(list)
    for v in g.nodes:
        buckets[(levels[v], core_of_op[v])].append(v)
    mapping, schedules, sid = {}, [[] for _ in range(num_cores)], 0
    for (r, k) in sorted(buckets):                 # 编号沿 (r, k) 递增 -> 商图无环
        members = sorted(buckets[(r, k)], key=lambda v: rank[v])
        step = max_ops or len(members)
        for i in range(0, len(members), step):     # 可选：按规模沿 sigma 切片
            for v in members[i:i + step]:
                mapping[v] = sid
            schedules[k].append(sid)
            sid += 1
    return mapping, schedules, levels
```

**（2）容量感知表调度的评分**（`solution/npu/listsched.py`，对应第 5 章的评分式与算法 5-1）

```python
def upward_rank(g, core_of_op, delay, bandwidth):
    """rank_u(v) = c_v + max_s (comm(v,s) + rank_u(s))，归一化到 [0, 1]。"""
    pb, rank = pair_bytes(g), {}
    for v in reversed(g.topo):
        best = 0.0
        for s in g.succs[v]:
            same = core_of_op[s] == core_of_op[v]
            comm = 0.0 if same else delay + pb[v].get(s, 0) / bandwidth
            best = max(best, comm + rank[s])
        rank[v] = max(1, g.cycles(v)) + best
    top = max(rank.values(), default=1.0) or 1.0
    return {v: r / top for v, r in rank.items()}


def pick(k):                                       # 为核 k 选下一个算子
    pool = ready[k][:TOP_CANDIDATES]               # 秩最高的 64 个就绪算子
    latest = max(range(4), key=lambda p: (pipe_free[k][p], -p))
    best_feasible, best_fallback = None, None
    for _, v in pool:
        alloc, dl, c = delta_live(v, k)            # 驻留净变化 Δlive 与对应容量 C
        if best_fallback is None or (dl, v) < best_fallback[:2]:
            best_fallback = (dl, v)
        if any(used[k][pos] + alloc[pos] > limit[pos] for pos in ("L1", "UB")):
            continue                               # 超过 alpha*C 的候选不参与评分
        p = PIPE_INDEX[g.pipe(v)]
        score = (rank[v] - mu * dl / c + (nu if p != latest else 0.0)
                 + noise * gumbel.get(v, 0.0))     # 评分式
        if best_feasible is None or (score, -v) > best_feasible[:2]:
            best_feasible = (score, -v, v)
    return best_feasible[2] if best_feasible else best_fallback[1]
```

##* 附录D 证明

**命题 3-1 的证明。** 任给 PARTITION 实例 $\{a_1,\dots,a_n\}$（PARTITION 是 NP-完全的[[karp]]），构造含 $n$ 个孤立算子的计算图，令算子 $v_i$ 的周期 $c_{v_i}=a_i$，所有算子位于同一条流水线，不设容量、带宽与通信代价。任一方案的 Makespan 为 $\max(L_0,L_1)$，其中 $L_k$ 为核 $k$ 上的周期之和，且 $L_0+L_1=\sum_i a_i$。于是存在 Makespan 不超过 $\frac{1}{2}\sum_i a_i$ 的方案，当且仅当原实例可以分成和相等的两部分。归约是多项式的；给定方案，其可行性与 Makespan 可在多项式时间内验证，判定版本属于 NP。故该判定问题是 NP-完全的。$\square$

**推论 3-3 中逐点最小性的证明。** 设 $l$ 为任一单调层指派。对算子按拓扑序归纳证明 $r(v)\le l(v)$。若 $v$ 无前驱，$r(v)=0\le l(v)$。否则由归纳假设，对每个前驱 $u$ 有 $r(u)\le l(u)$，于是

$$
r(v)=\max_{(u,v)\in E_{\mathrm{op}}}\bigl(r(u)+\mathbb{1}[c(u)\ne c(v)]\bigr)\le\max_{(u,v)\in E_{\mathrm{op}}}\bigl(l(u)+\mathbb{1}[c(u)\ne c(v)]\bigr)\le l(v)
$$

最后一步用到 $l$ 的单调性。又由[@eq:level]，$r$ 本身满足单调条件，所以 $r$ 是所有单调层指派中逐点最小的一个。$\square$
